# Excel 合并工具：给你自己看的说明

## 这个作品能证明什么
你能帮客户把很多格式不一致的 Excel/CSV 合并成一份干净报表。这是 Upwork 上很常见的需求，
常见关键词：`excel merge`、`combine spreadsheets`、`data cleaning`、`excel automation`、`python excel`。

## 放到 Upwork 作品集
1. 标题：`Merge & Clean Multiple Excel/CSV Files into One Report (Python)`
2. 图片：上传 `docs/before.png` 和 `docs/after.png`
3. 描述：可以直接复制 README.md 里 “The problem” 和 “What this tool does” 两段
4. 链接：填这个 GitHub 仓库的地址（需要把仓库设为公开）

## 在你自己电脑上运行（Windows）
1. 安装 Python：https://www.python.org/downloads/ ，安装时勾选 “Add Python to PATH”
2. 下载本仓库，打开 `excel-merge` 文件夹，在地址栏输入 `cmd` 回车
3. 依次输入：
   ```
   pip install -r requirements.txt
   python make_sample_data.py sample_data
   python merge_excel.py sample_data -o output\merged_report.xlsx
   ```
4. 打开 `output\merged_report.xlsx` 看结果

## 接到真实单子时
