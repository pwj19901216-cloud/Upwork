# 网页抓取作品：给你自己看的说明

## 这个作品能证明什么
你能把一个网站上成百上千条数据（商品、联系人、房源、职位等）抓下来，整理成干净的 Excel。
Upwork 上常见关键词：`web scraping`、`data scraping`、`scrape website to excel`、`data extraction`、`lead list`。

## 放到 Upwork 作品集
1. 标题：`Scrape 1,000 Products from a Website into Excel (Python)`
2. 图片：上传 `docs/result.png`
3. 描述（600 字符以内，可直接粘贴）：
   ```
   Problem: collect every product from a catalogue website (50 list pages, 1,000 detail pages) into a usable spreadsheet.

   Solution: a Python scraper that follows pagination, downloads detail pages in parallel with polite rate limits and retries, and turns prices, star ratings and stock text into clean numbers.

   Result: 1,000 products with 0 failures, delivered as Excel (with category summary and clickable links) and CSV.
   ```
4. 链接：https://github.com/RoyPan-Work/Upwork/tree/main/web-scraper

## 接网页抓取单子前要先判断
- 只接抓取**公开信息**的单子；需要登录别人账号、绕过验证码或付费墙的不要接
- 网站条款明确禁止抓取的（很多大型平台如 LinkedIn、Amazon），风险高，新手不要接
- 抓取个人信息（邮箱、电话）要格外小心，涉及隐私法规
- 拿不准时把任务描述发给我，我帮你判断

## 在你自己电脑上运行（Windows）
```
pip install -r requirements.txt
python scrape_books.py --max-pages 2
```
先用 `--max-pages 2` 快速测试，只抓 40 本书，大约半分钟。
